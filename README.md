
# Imtiyaz Ahmed - Personal Portfolio

A personal portfolio website showcasing Imtiyaz Ahmed's background, projects, technical skills, experience, education, and certifications.

The website features a modern dark-themed design with animated elements, responsive layouts, and sections highlighting his journey toward a career in software development.

## 🌐 Live Website

The project is hosted using **Vercel**.

> [Live Demo](https://imtiyazahmed.vercel.app/)

## Features

- **Personal Introduction:** Overview of professional interests and career goals.
- **About:** Background, academic information, and personal profile.
- **Projects:** Showcase of software projects, including a C-based Hospital Management System.
- **Skills & Tools:** Highlights of programming, version control, productivity tools, cybersecurity, and AI-assisted development.
- **Experience:** Community involvement and activities.
- **Education:** Academic background.
- **Certifications:** Courses and achievements with verification links where available.
- **Contact:** Direct access to email, GitHub, and LinkedIn.
- **Interactive UI:** Animated transitions, scrolling effects, a responsive navigation menu, and email-copy functionality.

## Technologies Used

- **HTML5** — Page structure and content.
- **CSS3** — Styling, responsive layouts, animations, and visual effects.
- **JavaScript** — Interactive components and dynamic behavior.
- **Google Fonts** — Inter and Space Grotesk typography.

## Running Locally

This is a static website and does not require a backend or package installation.

1. Open `index.html` in a web browser.
2. For a more convenient development experience, use a local development server through your preferred code editor.

An internet connection is needed to load Google Fonts from Google Fonts' hosted service.
